# Concurrent Container Factory Simulation
A Java multithreading project simulating a container factory with coordinated producers, packers, and transporters.
We run the program through the MainFabrica class

## Features
- Shared conveyor belt with limited capacity
- Producer-Packer-Transporter coordination
- Semaphore-based resource management
- Wait/Notify synchronization
- Thread-safe operations

## Skills Demonstrated
- Java Multithreading
- Synchronization (synchronized, wait/notify)
- Semaphore implementation
- Concurrent programming patterns
- Thread coordination and communication
